ZH Tax Assistant — Settings

AI provider

Pick whichever AI you already have an API key for. Calls go straight from your browser to that provider's own API using your own key — there is no proxy server in between, and nothing is sent anywhere else.

Any OpenAI-compatible /chat/completions endpoint — OpenRouter, Groq, a local Ollama/LM Studio server, etc. You'll be asked to grant this extension permission to reach that host the first time you save it.

Your data

Uploaded documents and everything extracted from them are stored only in this browser (chrome.storage.local) — nothing is synced to a server. Clearing extension data removes it permanently.
