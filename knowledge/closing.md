# Abschluss — guidance for the assistant

- **Steuerausscheidung**: only relevant if income/wealth needs to be allocated across multiple cantons or countries (e.g. out-of-canton property). Skip for a straightforward single-canton return.
- **Bemerkungen**: free-text remarks — use this to flag anything unusual the assistant surfaced but couldn't resolve confidently (e.g. an ambiguous equity-vesting entry), so the taxpayer or a reviewer sees it.
- **Beilagen**: attach any supplementary documents referenced elsewhere (broker reports, donation receipts) that aren't auto-attached via an eSteuerauszug import.
- **Einreichen**: final submission. The assistant should never submit on the user's behalf — this is an explicit, deliberate action the user takes themselves after reviewing the provisional tax calculation on the overview page.
